# DLsite 下载器

DLsite 漫画下载工具，支持自动登录、浏览已购买作品并下载。
本项目高度依赖dlsite-async项目。

## 安装使用

### 1. 安装依赖
```
pip install -r requirements.txt
```

### 2. 运行程序
```
python main.py
```

### 3. 使用流程
1. 程序启动后自动检测本地代理设置。
2. 首次使用需输入用户名和密码登录。
3. 登录成功后，会自动拉取 DLsite Play 书架中的已购作品列表。
4. 在交互界面输入作品号（或通过 `search` 命令搜索）进行下载。
5. 程序侦测文件类型，自动执行解混淆并输出下载。

## 主要功能

- **自动登录**：支持凭据保存和自动登录
- **代理检测**：自动检测系统代理设置
- **作品浏览**：显示已购买的图书类作品（漫画、电子书）
- **格式支持**：全面支持 DLsite Play 生态的多种受保护及公开格式（支持原生解密/解扰）：
  - **Ebook 阅览器格式** (`ebook_fixed`, `ebook_webtoon`, `voicecomic_v2`)：支持自动解密与有声漫画音频下载。
  - **Epub 阅览器格式** (`epub`)：支持基于 CSR 协议下载混淆图集并自动重排瓦片恢复原图。
  - **Legacy 旧版阅览器格式** (`image`, `pdf`)：完美支持只允许在线阅览的多页 PDF/画集，自动提取并进行马特赛特旋转密码解密，保存为高清图片集。
  - **其他常规下载**：支持普通无加密的 PDF、Zip、图片直下。

## 下载文件位置

程序会自动按类型组织解密后的文件结构：
```text
downloads/
└── 作品名称_产品ID/
    ├── ebook_xxxx/           # Ebook提取：单页解密图集及音频附件
    ├── epub_fixed_xxxx/      # Epub提取：固定版式去混淆图集
    ├── epub_reflowable/      # Epub提取：流式版式原生 .epub 文件
    ├── pages_xxxx/           # Legacy在线特供：解密的在线 PDF/画集图存
    └── single_files/         # 其他常规单文件提取
```

## 常用交互命令

在作品选择界面的“请选择：”提示符下，除了直接输入序号，还可以使用以下高级命令：

- **搜索作品**：输入 `search <关键词>` 开始搜索当前藏书
- **退出搜索**：输入 `reset` 退出搜索结果并回到完整列表
- **翻页指令**：输入 `n` (下一页)，`p` (上一页)，或 `j <页数>` (跳转到某页)
- **清除凭证**：
  - 输入 `clear`：彻底清除账号密码与最近的会话信息
  - 输入 `clear credentials`：仅清除账号密码
  - 输入 `clear session`：仅清除缓存的登录 Session
- **查看代理日志**：在外部终端输入 `type dlsite_downloader.log | findstr "代理"`

## 注意事项

1. **账户要求**：需要有效的 DLsite 账户和已购买的作品
2. **网络连接**：需要稳定网络，程序会自动处理代理设置
3. **安全提醒**：登录信息以明文保存在本地，请注意计算机安全
4. **使用规范**：请遵守 DLsite 使用条款，仅下载已购买作品
