# DLsite 下载器

DLsite 电子书下载工具，支持自动登录、浏览已购买作品并下载。

## 安装使用

### 1. 安装依赖
```
pip install -r requirements.txt
```

### 2. 运行程序
```
python main.py
```

### 3. 使用流程
1. 程序启动后自动检测代理设置
2. 首次使用需输入用户名和密码登录
3. 可选择保存登录信息以便下次自动登录
4. 选择要下载的作品（输入序号）
5. 等待下载完成

## 主要功能

- **自动登录**：支持凭据保存和自动登录
- **代理检测**：自动检测系统代理设置
- **作品浏览**：显示已购买的图书类作品（漫画、电子书）
- **格式支持**：“本作品是浏览器视听（漫画阅览器）作品。”“该作品可直接在浏览器上进行浏览
另外，如需下载观看，请准备「DLsite Viewer」。”（CPD无法下载）

## 下载文件位置

```
downloads/
└── 作品名称_产品ID/
    └── 文件内容/
```

## 常用命令

- 清除保存的登录信息：在作品选择界面输入 `clear`
- 查看代理日志：`type dlsite_downloader.log | findstr "代理"`

## 注意事项

1. **账户要求**：需要有效的 DLsite 账户和已购买的作品
2. **网络连接**：需要稳定网络，程序会自动处理代理设置
3. **安全提醒**：登录信息以明文保存在本地，请注意计算机安全
4. **使用规范**：请遵守 DLsite 使用条款，仅下载已购买作品

## 运行要求

- Python 3.11+
